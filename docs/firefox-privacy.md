# KISS Translator (finalpi) 数据传输说明

维护者：finalpi，联系邮箱：finalpi@outlook.com。
源代码：https://github.com/finalpi/kiss-translator 。

本扩展提供网页、划词、输入文本和字幕翻译。联网翻译时，待翻译内容会发送到
所选翻译服务或用户配置的 API 地址。AI 翻译可能同时发送网页标题、描述、摘要、
上下文及用户配置的提示词。开启自动翻译的页面可能自动触发这些请求。
请勿翻译不希望交给所选服务的敏感内容。

服务需要认证时，配置的 API 密钥或认证信息会发送给该服务。
使用自定义 API 时，接收方由用户配置决定。服务方的数据保存与处理方式以其
隐私政策为准；本扩展不能替服务方承诺保存期限或删除结果。

启用同步并配置同步地址、凭据及加密口令后，设置、自定义规则和生词本会同步
到用户选择的 WebDAV、GitHub Gist 或 KISS-Worker。设置可能包含翻译服务密钥，
规则可能包含网站域名或 URL。个人同步的内容在本地加密后传输，外层文件键名
及更新时间不加密；连接所用的认证信息仍会提供给同步服务。
“分享规则”会把规则以明文发送到所配置的 Worker，供订阅使用。

Firefox 中，同步及规则分享另需允许“技术和交互数据”，这里用于设置数据传输。
可在 `about:addons` → 本扩展 → “权限和数据”中开启或撤销。
未允许时会阻止新的同步/规则分享操作；撤销不会删除远端已有数据，也不会撤回
已发送或正在传输的请求。普通翻译不依赖此可选授权。

扩展还可能请求订阅规则、版本信息、词典或发音资源。网络服务可收到正常连接
附带的 IP 地址和请求元数据。站点标题、规则中的网站地址等可能涉及浏览活动。
本次修改未增加统计、广告或错误日志上报服务。

设置与缓存保存在浏览器本地。可通过扩展设置清理相应数据或卸载扩展；远端同步
副本需要在所选同步服务中另行删除。关闭同步配置可停止后续自动同步。

声明分类：网页内容、认证信息、浏览活动；可选的技术和交互数据用于设置同步。
此说明适用于本仓库的 finalpi Firefox 构建，不代表原项目作者的独立承诺。
